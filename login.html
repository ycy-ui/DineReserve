选择入口

同一套订位引擎，两个入口：客人在线查空桌、订位、改期取消；商家看平面图、接电话单、管理候补与报表。

🧑‍🍳

客人 · Diner

无需登录，选日期、时间与人数即可查看实时空桌并完成订位。

  • 15 分钟起订网格 · 提前 90 天
  • 8 位订位号 + 截止时间 + 提醒
  • 凭签名链接自助改期 / 取消
进入客人端 → 订位数据保存在本机浏览器（静态演示）；真实系统通过 API 落库。
🖥️

商家 · Merchant

前台控制台：平面图、入座 / 爽约 / 释放、电话预订、候补、报表。

  • 实时平面图（每 5 秒刷新）
  • 电话单与候补队列
  • 占用 / 风险报表
没有商家账号？使用部署令牌
离线演示（无需 API）→ 演示账号：manager@dinereserve.local / DemoPass123!（前台 host 账号同理）。登录后会拿到 8 小时有效的会话令牌，商家端用 Authorization: Bearer … 调用商家 API。没有启动 PHP 服务时（例如 GitHub Pages），请用离线演示。
