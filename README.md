# DineReserve

**An Online Restaurant Booking and Table Management System**

Software Engineering course project (Task 1 — Project Proposal) · Macau University of Science and Technology, School of Computer Science and Engineering.

## Project Website

- Repository: https://github.com/ycy-ui/DineReserve
- GitHub Pages: https://ycy-ui.github.io/DineReserve/

## Problem

Small and medium-sized restaurants still take reservations by phone and paper book:

1. Phone overload during rush hours
2. Manual table allocation errors
3. No-shows without reminders
4. Empty tables after late cancellations
5. No operating data for managers
6. Commission and lock-in of commercial booking platforms

## Proposed Solution

A self-hosted web system where diners check real-time availability, book in under a minute, join a waitlist and receive automatic reminders, while staff manage floor plan, check-ins, no-shows and occupancy reports. Built on the open-source TastyIgniter platform with new automatic data-processing features: waitlist promotion, scheduled reminders, occupancy reporting and a no-show risk score.

## Success Metrics (proposed targets)

| Metric | Current | Target |
|---|---|---|
| No-show rate | 10–20% | < 5% |
| Online bookings | none | ≥ 70% |
| Booking time | 3–5 min | < 60 s |
| Recovered covers | 0 | +10% peak |
| Page response | n/a | < 2 s |
